# Portfolio launch checklist

## GitHub Pages deployment

This static HTML/CSS/JavaScript portfolio is already published from the `main` branch of the `Muhammad-Mohsin-Tallat--Portfolio-` repository. GitHub Pages serves the repository root, and the live site is:

https://muhammadmohsin1999-cmacgm.github.io/Muhammad-Mohsin-Tallat--Portfolio-/

To publish future changes:

1. Upload or commit the website files to the repository's `main` branch. Keep `index.html`, `style.css`, `script.js`, `portfolio-projects.html`, `portfolio-projects.css`, and `portfolio-projects.js` in the repository root.
2. Keep `muhammad-mohsin-tallat.jpg` in the repository root; the homepage references it there.
3. In the repository, open **Settings → Pages** and confirm deployment is from the `main` branch and `/ (root)`.
4. Wait for the Pages deployment to finish, then check the live site, project demos, profile image, navigation, 404 page, and responsive layout.

## Before publishing

1. Confirm the name, phone number, email, employment details, dates and metrics are accurate and that you want them public.
2. Decide which contact details you want publicly visible. The portfolio has email, WhatsApp and an Al-Khobar Google Maps search link; it does not collect or store visitor data.
3. The four project cards link to independent HTML/CSS/JavaScript portfolio app prototypes: employee tracking, inventory control, fleet dispatch, and a safety action register. They use sample data saved in the visitor's browser only; they have no backend, shared real-time database, authentication, or employer-system connection. Do not describe them as deployed client or employer systems.
4. Keep the GitHub repository private if you do not want the source and resume image publicly browsable; the deployed website itself will still be public.
5. Use only photos and other media you have permission to publish. The profile photo in this site was supplied for this request.

## Google search setup

1. Add and verify this site in Google Search Console using the verification method Google provides.
2. Submit this sitemap URL: https://muhammadmohsin1999-cmacgm.github.io/Muhammad-Mohsin-Tallat--Portfolio-/sitemap.xml
3. Use URL Inspection to check the homepage and request indexing. Indexing and ranking are controlled by Google and are not guaranteed.
4. The homepage includes descriptive metadata, a canonical URL, index/follow robots directives, and Person schema. `robots.txt` references the sitemap.

## Privacy, analytics and backups

- Google Analytics is not included. Add it only if you choose a measurement ID and determine the applicable privacy and consent requirements.
- No cookie banner is included because this static portfolio does not set analytics or advertising cookies and has no visitor-data form. Reassess before adding third-party tracking, forms, or embedded services.
- Keep a second backup in a separate secure location and verify that the image and all website files are included.
